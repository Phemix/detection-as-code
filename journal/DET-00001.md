# DET-00001 — LSASS Memory Dump via ProcDump or comsvcs.dll

## Origin

Backfilled when the rule-journal system was introduced. LSASS credential
dumping via ProcDump (`-ma` flag) or the `comsvcs.dll` MiniDump export is
one of the most common post-exploitation credential-access techniques
(T1003.001) and lacked any documented rationale trail before this.

## Baseline Behavior

ProcDump against `lsass.exe` and `rundll32.exe` invoking `comsvcs.dll`
MiniDump are both rare in normal endpoint activity. SYSTEM-context
invocations parented by `mmc.exe` are excluded as a known legitimate
diagnostic path.

## Tuning History

- `2024-01-15` — Initial rule created.

## Known False Positives

- Legitimate memory diagnostic tools run in an authorized change window
  — verify against the change ticket before escalating.
- Vendor-approved debugging sessions with documented approval — confirm
  approval ticket ID before closing as benign.
